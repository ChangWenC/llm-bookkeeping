# Failure cases that must remain visible

- Source checkpoint means saved material; it does not finish review or publication.
- Complete capture plus half-reviewed chunks remains partial. No facts and no data are different states.
- A parsed same-text message can be a real repeated event; paths/mtime/UUID shapes are not identity/classification proof.
- UTC cutoff is frozen per round. Local date is historical, not recalculated using today's timezone.
- Application assigns permanent fact/chunk/operation IDs; model assigns only local candidates.
- Persist pending patch before file intent so a crash cannot orphan the journal update.
- Facts export before Wiki consumers; lock and index failures cannot revoke semantic commit.
- Compare target with both saved old and desired content after interruption. Unknown content conflicts, never overwrite it.
- Analytics reads explicit professional projections; original mixed content and raw chat never enter its outputs.
- Missing implementation returns an execution failure; ordinary known pending/partial returns a successful command with detailed states.
